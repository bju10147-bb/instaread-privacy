인스타 맛집 지도 핫플 저장 instaRead (com.bb.instaRead)
시행일: 2026년 11월 1일

이 방침은 instaRead 앱(이하 "앱")이 어떤 정보를 다루는지 설명합니다. 앱은 회원가입이 없고, 개발자가 운영하는 서버가 없습니다. 개발자는 사용자의 개인정보를 수집하거나 저장하지 않습니다. 저장한 장소와 게시물은 사용자의 기기에만 있습니다.

1. 앱이 다루는 정보

항목언제목적어디로
공유한 게시물 링크사용자가 Instagram·YouTube에서 앱으로 공유할 때게시물의 공개 제목·설명을 읽어 장소를 찾음해당 링크의 공개 페이지에 요청합니다(Instagram/YouTube). 결과는 기기에만 저장됩니다.
게시물 공개 텍스트(캡션)위와 같음장소 이름·주소 추출, 보관함 검색기기 안에서 처리합니다. 사용자가 Gemini API 키를 등록한 경우에만 아래 3번처럼 Google Gemini로 보냅니다.
장소 주소장소를 저장할 때지도 좌표 변환기기의 Android 위치 변환(Geocoder) 서비스를 사용합니다.
현재 위치사용자가 지도에서 내 위치를 볼 때(권한 허용 시)지도에 내 위치 표시기기 화면에만 표시하며 저장하거나 전송하지 않습니다.
메모·컬렉션·내가 붙인 사진사용자가 입력할 때보관함 정리기기 내부 저장소에만 저장됩니다.
Gemini API 키사용자가 직접 입력할 때Gemini 분석 요청기기의 암호화 저장소에만 저장됩니다.

앱은 Instagram 로그인이나 계정 정보를 요구하지 않으며, 게시물 사진을 기기에 내려받지 않습니다.

2. 권한

  • 위치(대략·정확): 지도에서 내 위치를 보여 줄 때만 씁니다. 거부해도 다른 기능은 쓸 수 있습니다.
  • 인터넷·네트워크 상태: 공유한 링크 읽기, 지도, 광고에 사용합니다.
  • 진동: 저장 완료 등 짧은 피드백에 사용합니다.

3. 제3자 서비스

  • Google 지도 SDK: 저장한 장소를 지도에 표시합니다. Google 개인정보처리방침
  • Google Gemini API (선택): 사용자가 자신의 API 키를 등록한 경우에만, 장소를 찾지 못한 게시물의 공개 텍스트와 공개 이미지 주소를 Google에 보내 장소 이름·주소를 분석합니다. 사용자 계정의 Gemini 약관이 적용됩니다.
  • Google ML Kit 텍스트 인식: 이미지 속 글자를 기기 안에서 읽습니다.
  • Google AdMob: 광고를 표시할 때 광고 ID 등 기기 식별자와 앱 사용 정보가 Google에 전송될 수 있습니다. 현재 버전은 광고를 표시하지 않습니다. Google 광고 정책

4. 백업

설정 > 내보내기를 누르면 저장한 장소·게시물을 사용자가 고른 위치에 파일로 저장합니다. Android 자동 백업이 켜져 있으면 앱 데이터베이스가 사용자의 Google 계정 백업에 포함될 수 있습니다.

5. 보관과 삭제

장소·게시물은 앱에서 지우거나 앱을 삭제하면 기기에서 지워집니다.

6. 아동

앱은 만 13세 미만 아동을 대상으로 하지 않습니다.
